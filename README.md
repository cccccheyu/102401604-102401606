\# 校园失物招领系统

结对作业：学号102401604 \& 102401606

技术栈：HTML + CSS + JavaScript，浏览器localStorage本地存储，\*\*不需要后端服务器\*\*



\## 目录结构

lost-found/

├─ index.html        # 首页：浏览全部失物招领、搜索物品

├─ publish.html      # 发布页面：填写寻物 / 招领表单

├─ detail.html       # 详情页面，查看信息、修改物品状态

├─ css/style.css     # 页面样式

├─ js/main.js        # 业务逻辑，本地存储、搜索、状态修改



**## 运行说明**

**1. 将整个lost-found文件夹下载解压**

**2. 使用谷歌Chrome浏览器，双击打开 index.html**

**3. 功能说明**

**- 首页浏览所有寻物、招领卡片；顶部输入物品名字进行搜索**

**- 点击发布按钮，填写表单发布新信息**

**- 点击卡片查看详情，一键复制联系方式**

**- 在详情页面，可以标记【已找到】/【已归还】**

**> ⚠️ 数据保存在浏览器本地存储，清空浏览器缓存会丢失所有数据**
